# History Core

History Core is an interactive EdTech game that transforms history learning from passive memorization into an immersive experience.

Instead of only reading about historical events, students explore historical environments, interact with the story, complete tasks, and learn through gameplay.

## Problem

Traditional history education often relies heavily on textbooks, lectures, and memorization. This can make it difficult for students to stay engaged and understand historical events in context.

## Solution

History Core uses game-based learning to make history interactive. Students enter historical environments and learn by exploring, completing challenges, and interacting with educational content.

The current MVP demonstrates the core gameplay and learning experience.

## Key Features

- Interactive historical environments
- Exploration-based learning
- Educational tasks integrated into gameplay
- Immersive 3D experience
- Game-based approach to history education

## Technology

- Unity
- C#
- 3D game development
